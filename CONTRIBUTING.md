# Contributing

Thanks for your interest in contributing to this project. We welcome improvements, bug reports, feature ideas, and pull requests.

## Code of Conduct

This project is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md). By participating, you agree to uphold it.

## How to Contribute

### Reporting Bugs

Before opening a bug report, please:

- Check the [existing issues](https://github.com/MaxAndreev27/vue-dashboard/issues) to avoid duplicates.
- Confirm the issue is reproducible.
- Include the environment details, steps to reproduce, expected behavior, and actual behavior.
- Attach logs, screenshots, or relevant code snippets when helpful.

### Suggesting Features

Open an issue describing:

- The problem you want to solve
- The desired outcome
- Any examples or alternatives you considered

### Contributing Code

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make the smallest, focused change that addresses the issue.
4. Keep code clean and readable.
5. Run the relevant checks before submitting your change.
6. Open a pull request with a clear description and testing notes.

## Local Development

### Prerequisites

- Node.js 22 or newer
- npm

### Installation

```bash
npm install
```

### Run the app

```bash
npm run dev
```

### Run tests

```bash
npm run test:unit
npm run test:e2e
```

### Lint and format

```bash
npm run lint
npm run format
```

## Pull Request Guidelines

- Keep pull requests focused on one topic.
- Write clear commit messages.
- Update documentation when behavior changes.
- Add or update tests when possible.
- Ensure CI checks pass before requesting review.

## Review Process

Maintainers review pull requests on a best-effort basis. We may request changes before merging if the fix or design needs adjustment.

## Questions

If you have questions, please open a discussion or contact the maintainers through the repository's support channels.
