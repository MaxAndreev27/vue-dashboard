# Support

Thanks for using this project. Below are the main ways to get help.

## Questions and Help

- Check the [README](./README.md) for setup and usage instructions.
- Search existing [issues](https://github.com/MaxAndreev27/vue-dashboard/issues) for similar problems.
- Open a new issue if you cannot find an answer.

## Bug Reports

When reporting a bug, please include:

- A clear title
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details (OS, browser, Node.js version, package manager)
- Screenshots or logs if relevant

## Feature Requests

Feature requests are welcome. Please open an issue describing the problem, the use case, and the desired outcome.

## Community Guidelines

Please review the [Code of Conduct](./CODE_OF_CONDUCT.md) before participating in issues, discussions, or pull requests.

## Response Time

Response times vary depending on maintainer availability. We appreciate your patience while we review reports and questions.
