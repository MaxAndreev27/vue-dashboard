# Security Policy

## Supported Versions

The project maintainers aim to support the current development version and the most recent stable release. Security fixes are prioritized for active branches.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues or pull requests.

Instead, report them privately by:

- Opening a private security advisory via GitHub, if available for this repository
- Contacting the repository maintainers through the GitHub profile or project contact channel
- Providing as much detail as possible, including affected versions, reproduction steps, impact assessment, and any suggested fix

We ask that you allow us a reasonable amount of time to investigate and respond before making any public disclosure.

## Response Expectations

We will do our best to:

- Acknowledge receipt of the report in a timely manner
- Assess the issue and determine its severity
- Provide updates as the investigation progresses
- Release a fix or mitigation when appropriate

## Disclosure Policy

We follow responsible disclosure practices. Public advisories should only be created after a fix is available or after coordination with the maintainers.
